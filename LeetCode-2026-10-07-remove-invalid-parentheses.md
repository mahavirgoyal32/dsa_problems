### 📝 Problem Description

Given a string s that contains parentheses and letters, remove the minimum number of invalid parentheses to make the input string valid.

Return a list of unique strings that are valid with the minimum number of removals. You may return the answer in any order.

 
Example 1:


Input: s = &quot;()())()&quot;
Output: [&quot;(())()&quot;,&quot;()()()&quot;]


Example 2:


Input: s = &quot;(a)())()&quot;
Output: [&quot;(a())()&quot;,&quot;(a)()()&quot;]


Example 3:


Input: s = &quot;)(&quot;
Output: [&quot;&quot;]


 
Constraints:


	1 <= s.length <= 25
	s consists of lowercase English letters and parentheses &#39;(&#39; and &#39;)&#39;.
	There will be at most 20 parentheses in s.

## AI Generated Solution

To tackle the problem of removing invalid parentheses from a string, we need a systematic approach since the problem is marked as "Hard". The objective is to generate all possible strings that can be obtained by removing invalid parentheses such that the resulting strings are valid.

**Understanding the Problem:**
A string is considered valid if the parentheses are balanced. For example:
- "(()))" → invalid
- "(())" → valid
- "(()" → invalid

### Approach:
1. **Count Invalid Parentheses**: We need to count how many closing and opening parentheses are mismatched, as this determines how many parentheses we need to remove.
  
2. **Depth-First Search (DFS)**: We can use DFS to explore all possible valid strings generated by removing parentheses. 
   - For each character in the string:
     - If the character is an opening parenthesis '(', we can either include it or exclude it.
     - If it's a closing parenthesis ')', we can include it only if we have an unmatched opening parenthesis to pair it with.

3. **Check Validity**: While generating the strings, we need to check if the current string formed is valid. A helper function for validating the string is essential.

4. **Use a Set to Avoid Duplicates**: Since we might generate the same string multiple times, a set is useful to keep track of unique valid strings.

5. **Termination Condition**: When the string index exceeds the given string length, we check if the generated string is valid.

### C++ Implementation:
Here’s a step-by-step implementation based on the description above:

```cpp
#include <iostream>
#include <vector>
#include <set>
#include <string>

class Solution {
public:
    std::set<std::string> result;

    void dfs(std::string s, int index, int leftCount, int rightCount, int leftToRemove, int rightToRemove) {
        // If we reach the end of the string
        if (index == s.size()) {
            if (leftToRemove == 0 && rightToRemove == 0) {
                result.insert(s); // Add valid result to set
            }
            return;
        }

        char c = s[index];

        // Decision to include the current character
        if (c == '(') {
            // Case 1: Exclude current '(' if we can remove it
            if (leftToRemove > 0) {
                dfs(s, index + 1, leftCount, rightCount, leftToRemove - 1, rightToRemove);
            }
            // Case 2: Include current '('
            dfs(s, index + 1, leftCount + 1, rightCount, leftToRemove, rightToRemove);
        }
        else if (c == ')') {
            // Case 1: Exclude current ')' if we can remove it
            if (rightToRemove > 0) {
                dfs(s, index + 1, leftCount, rightCount, leftToRemove, rightToRemove - 1);
            }
            // Case 2: Include current ')', only if valid
            if (leftCount > rightCount) {
                dfs(s, index + 1, leftCount, rightCount + 1, leftToRemove, rightToRemove);
            }
        }
        else {
            // Case when it's a non-parenthesis character
            dfs(s, index + 1, leftCount, rightCount, leftToRemove, rightToRemove);
        }
    }

    void findMinRemoval(std::string s, int &leftToRemove, int &rightToRemove) {
        for (char c : s) {
            if (c == '(') {
                leftToRemove++;
            }
            else if (c == ')') {
                if (leftToRemove > 0) {
                    leftToRemove--;
                } else {
                    rightToRemove++;
                }
            }
        }
    }

    std::vector<std::string> removeInvalidParentheses(std::string s) {
        int leftToRemove = 0, rightToRemove = 0;
        findMinRemoval(s, leftToRemove, rightToRemove);
        dfs(s, 0, 0, 0, leftToRemove, rightToRemove);
        return std::vector<std::string>(result.begin(), result.end());
    }
};
```

### Explanation:
1. **Count Invalid Parentheses**: The function `findMinRemoval` counts the number of unmatched opening `(` and closing `)` parentheses.

2. **DFS Function**: The `dfs` function is a recursive function that explores all combinations of removals. It checks for:
   - Whether to include or exclude a parenthesis based on the counted mismatches.
   - Validity of parentheses as it constructs valid strings.

3. **Result Collection**: Valid combinations are aggregated into a `set` to ensure uniqueness.

4. **Return Format**: Finally, we convert the set to a vector and return it.

### Complexity:
- **Time Complexity**: The approach depends on the number of combinations to generate valid parentheses, which can potentially lead to exponential complexity in the worst case.
- **Space Complexity**: The space complexity primarily comes from storing the results, which can also lead to exponential storage requirements.

This solution efficiently removes invalid parentheses while ensuring that each valid formation is captured without duplicates.
